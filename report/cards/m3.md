# What They Meant: Tiny Aya Global after preference training (DPO)

A LoRA adapter for Cohere Labs Tiny Aya Global (3.35B) from the project *What They Meant*, an RL environment for AI agents that
handle payments. The agent should ask one question that names the problem when a request does not match the customer's records,
and otherwise show a plain approval card and go ahead.

## Training
DPO with AlignTune, starting from the base model, on 496 curated preference pairs: the right move next to a mistake the base
model actually made. Beta 0.1, 1 epoch, learning rate 5e-6, LoRA rank 16.

## Results
We keep this adapter as a comparison point. At this learning rate it moved the weights only 3.3% as far as supervised
fine-tuning did, and it behaves almost exactly like the base model: on 41 held-out twin pairs inside the realistic app it still
pays most risky requests without approval. Its general skills match the base model (IFEval 68.0%, Global-MMLU English 50.0%,
MGSM 43.6%). The supervised fine-tuned and reinforcement-learning adapters in the same collection are the trained agents. Full
tables: https://github.com/nsharan2000/what-they-meant (`report/tables_generated.md`).

## Limitations
A research model trained on synthetic scenarios (all names, accounts and amounts are invented), English prompts and four
fictional apps. Do not let it move real money.

## Use
```python
from peft import PeftModel
from transformers import AutoModelForCausalLM
base = AutoModelForCausalLM.from_pretrained("CohereLabs/tiny-aya-global")
model = PeftModel.from_pretrained(base, "sharan-nagarajan/what-they-meant-tiny-aya-dpo")
```
Prompt format: tool calls are assistant text `<tool_call>{"name": ..., "arguments": ...}</tool_call>` and tool results come back
as user turns (`wtm/protocol.py` in the repository).
