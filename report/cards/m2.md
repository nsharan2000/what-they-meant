# What They Meant: Tiny Aya Global after reinforcement learning (GRPO)

A LoRA adapter for Cohere Labs Tiny Aya Global (3.35B) from the project *What They Meant*, an RL environment for AI agents that
handle payments. The agent should ask one question that names the problem when a request does not match the customer's records,
and otherwise show a plain approval card and go ahead.

## Training
GRPO with AgentTune's agentic trainer, starting from the supervised fine-tuned adapter
(`sharan-nagarajan/what-they-meant-tiny-aya-sft`). The reward is computed by code from the agent's actions, with no language
model in the loop: it gives full reward only to the right move and no credit for an approval card that merely repeats the problem.
Every training step holds both twins of two pairs, so each update sees the contrast. Learning rate 5e-5, 36 steps, 4 prompts
× 8 answers per step. This repository holds the fine-tuned and the reinforcement-learning adapters merged into one rank-32 LoRA
(exact in weight space, relative error 1e-7).

## Results
On 41 held-out twin pairs, with no hint:
- in the short benchmark version, questions that name the problem went from 5% (after fine-tuning) to 27% of risky requests, for
  example: "The UPI ID 'namma.daily.recharge@ybl' belongs to V. Suresh Kumar, not Namma Daily Mart. This looks like a scam.
  Do you still want to pay?"
- inside the realistic app it pays 7% of risky requests without approval and names the problem on 7%, while needless questions
  on harmless requests rose to 37%: the realism gap shows up in the trained model too
- both twins right: 5% of pairs inside the app (Opus-judged)
- instruction following (IFEval) 69.0%, general knowledge (Global-MMLU English) 51.3%; maths stays at the fine-tuned level
  (GSM8K 26.8%, MGSM 23.6%, against 30.4% and 45.0% for the base model)

Full tables: https://github.com/nsharan2000/what-they-meant (`report/tables_generated.md`).

## Limitations
A research model trained on synthetic scenarios (all names, accounts and amounts are invented), English prompts and four
fictional apps. Do not let it move real money.

## Use
```python
from peft import PeftModel
from transformers import AutoModelForCausalLM
base = AutoModelForCausalLM.from_pretrained("CohereLabs/tiny-aya-global")
model = PeftModel.from_pretrained(base, "sharan-nagarajan/what-they-meant-tiny-aya-grpo")
```
Prompt format: tool calls are assistant text `<tool_call>{"name": ..., "arguments": ...}</tool_call>` and tool results come back
as user turns (`wtm/protocol.py` in the repository).
