# What They Meant — M2 — GRPO on top of M1 (AgentTune), served as one stacked LoRA

A LoRA adapter for **Cohere Labs Tiny Aya Global** (3.35B) from the project *What They Meant*: payment agents that should ask one
question naming the clash when a request does not match what the customer means, and otherwise show a plain approval card.

## Training
GRPO (AgentTune
`create_agentic_trainer`, TRL backend, programmatic reward `wtm/reward.py` variant v2, no LLM in the loop) from merged M1: lr 5e-5,
36 steps × 4 prompts × 8 generations, β 0, every optimizer step holding both twins of two pairs at one realism level. This repo
holds M1 + M2 stacked into ONE rank-32 LoRA on the base model (exact in weight space, relative error 1e-7). The GRPO run moved the
weights by 21.8 % of SFT's change but did not learn the twin discrimination (it drifted toward asking on both twins).

## Evaluation
Held-out twin pairs (41 test pairs from 13 source posts + 13 held-out hard pairs) at four realism levels (toy L0r → realistic app
L2), with no instruction (P0) and a two-line hint (P2); Opus-judged paired pass, harm, needless questions, capability retention
(IFEval, GSM8K, Global-MMLU, MGSM) and SafeTune / AlignTune audits. Full tables, confidence intervals and caveats: the project
article (HF) and https://github.com/nsharan2000/what-they-meant (`report/tables_generated.md`).

## Limitations (read before use)
- **Research artefact, not a payment product.** On 41 held-out twin pairs the best Tiny Aya arm handles both twins correctly in at
  most ~10 % of pairs (Opus-judged); Claude Opus 5.5 reaches 27–66 % depending on the setting. Do not put it in front of money.
- After SFT the model looks records up and prefers approval cards over paying, but it does not reliably tell a clash from a
  normal request; GRPO made it ask more on both kinds of request.
- Maths regression after SFT: MGSM direct 45.0 % → 22.2 %, GSM8K 30.4 % → 25.6 % (IFEval and Global-MMLU unchanged).
- Synthetic scenarios only; all names, accounts and amounts are invented. English prompts; four fictional apps.

## Use
```python
from peft import PeftModel
from transformers import AutoModelForCausalLM, AutoTokenizer
base = AutoModelForCausalLM.from_pretrained("CohereLabs/tiny-aya-global")
model = PeftModel.from_pretrained(base, "sharan-nagarajan/what-they-meant-tiny-aya-grpo")
```
The prompt format (text tool protocol: `<tool_call>{"name": ..., "arguments": ...}</tool_call>`, tool results as user turns) is
documented in the repository (`wtm/protocol.py`).
