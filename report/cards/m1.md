# What They Meant: Tiny Aya Global after supervised fine-tuning

A LoRA adapter for Cohere Labs Tiny Aya Global (3.35B) from the project *What They Meant*, an RL environment for AI agents that
handle payments. The agent should ask one question that names the problem when a request does not match the customer's records,
and otherwise show a plain approval card and go ahead.

## Training
Supervised fine-tuning with AgentTune's distillation interface (loss on the assistant's turns only) on 904 curated look-up and
decision turns (dataset v1.2.1, selected with CuratorKIT). LoRA rank 16, alpha 32, on all seven projection layers; 2 epochs,
learning rate 1e-4, effective batch 16; 311 minutes on one DGX Spark.

## Results
On 41 held-out twin pairs inside the realistic app, with no hint, compared with the base model:
- pays a risky request without approval: 73% → 10%
- checks the records before deciding: 5% → 95%
- shows a legitimate payment as a proper approval card: 5% → 83%
- instruction following (IFEval) 67.5% → 67.5%; general knowledge (Global-MMLU English) 49.8% → 51.3%; maths dropped
  (GSM8K 30.4% → 25.6%, MGSM 45.0% → 22.2%)

It rarely tells the risky twin from the harmless one: on risky requests it usually shows the approval card instead of asking,
and it gets both twins right on 2% of pairs inside the app (Opus-judged). Full tables:
https://github.com/nsharan2000/what-they-meant (`report/tables_generated.md`).

## Limitations
A research model trained on synthetic scenarios (all names, accounts and amounts are invented), English prompts and four
fictional apps. Do not let it move real money.

## Use
```python
from peft import PeftModel
from transformers import AutoModelForCausalLM
base = AutoModelForCausalLM.from_pretrained("CohereLabs/tiny-aya-global")
model = PeftModel.from_pretrained(base, "sharan-nagarajan/what-they-meant-tiny-aya-sft")
```
Prompt format: tool calls are assistant text `<tool_call>{"name": ..., "arguments": ...}</tool_call>` and tool results come back
as user turns (`wtm/protocol.py` in the repository).
